# Historical implementation — superseded before archival

Archived with user approval on 2026-11-05. Descriptor-loop restoration and named bandwidth acquisition were delivered and investigated during the earlier experiment, then replaced by `simplify-frame-performance-sessions`.

The shipped profiler performs ordinary one-frame replay in fresh processes, so no sustained descriptor/resource restoration is required. GUI counter capture requests all supported provider metrics; legacy CLI precision/bandwidth names alias `all`. No current `sustained-descriptor-lifetimes` or `bandwidth-counter-profile` specification is created from these historical deltas.
