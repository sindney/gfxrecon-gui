# Historical implementation — superseded before archival

Archived with user approval on 2026-11-05. The experiment's completed tasks and validation remain historical evidence. Its in-process repetition, warm-up, pacing, restoration and required named-counter profiles are **not the shipped design**.

The current implementation and specifications follow `simplify-frame-performance-sessions`: fresh outer replay runs, independent GPU timestamps and optional all-provider counters within the selected frame's correlated GPU interval. Current Perf controls, row selection/filtering and plotting behavior are documented in `openspec/specs/performance-dialog/spec.md`; the old delta requirements in this archive must not replace that specification.
